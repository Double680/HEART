Given a question and a hierarchical table with its caption and headers:
Question: <QUESTION> 
Table Caption: <CAPTION> 
Table Headers: <TABLES>
Extract IDs of useful rows and columns for the table to simplify the context. 
- The rows and columns should be precise that all useful rows and columns should be preserved, while additional redundant rows or columns should not be involved. 
- The output should be in folloing format within <answer> </answer> tags:
<answer>
Extract Row IDs: [R1, R2, ...]
Extract Column IDs: [C1, C2, ...]
</answer>
where all R1, R2, ... and C1, C2, ... should be integer IDs. 
For example, the following output are legal:
<answer>
Extract Row IDs: [3, 6, 7]
Extract Column IDs: [2, 5, 8, 10]
</answer>
